# Retool + BrowseComp 1:1 + Qwen3-8B（H100）

测试节点：`node2700`；GPU：8×H100 80GB。temperature 0、seed 2026、
固定 n8192 顺序、300 秒业务预热 + 1200 秒正式测量；并发为 c384/c512/c640，
共四种方法、12 组实验。普通 GPU `mem_fraction_static=0.80`，搜索 GPU7 为 0.60。

固定序列为 Math/QA 各 4096，样本池 seed=2026、任务顺序 seed=2027；本轮恢复文件 SHA256 为
`94027490e74f441311451e1f230396b12959a3d5fb006202e956197e40a913a3`。
PD 方法保持原表 2P:6D 配置；当前新方法沿用默认 Q high=16、low=4、工具/Direct 1 秒和原表 Host 配置，
原生 Mooncake 保留原生 HiCache/Mooncake 机制。

当前新方法统一使用 D→P Host 总量 512 GiB（256 GiB/P）和 P→D Host 总量
256 GiB（128 GiB/P）；两者均为两台 Prefill 引擎合计。

## 当前新方法路径统计

以下计数限定在正式 1,200 秒窗口，按 `snapshot` / `req` 去重；窗口首尾的在途
snapshot 会使完成、绑定、写入、恢复与释放相差少量，不能将差值直接解释为 KV 丢失。

| 并发 | D→P Direct | D→P Slow Host | D→P 重算 | Direct/Slow/重算 | P→D Direct | P→D Host | Host→D 恢复 |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 384 | 20,829 | 74 | 0 | 99.65% / 0.35% / 0.00% | 26,925 | 0 | 0 |
| 512 | 21,571 | 378 | 0 | 98.28% / 1.72% / 0.00% | 3,603 | 24,587 | 24,585 |
| 640 | 18,690 | 2,564 | 390 | 86.35% / 11.85% / 1.80% | 5,741 | 22,049 | 22,088 |

c384 的 D→P Slow Host 写入、D 源释放、Host→P 恢复与 Host extent 释放均为
74 次；其中 1 次恢复来自窗口前写入，另 1 次窗口内写入随后走 application-final。
Direct complete 比 bind 多 2 次，来自窗口末秒完成、窗口外绑定。另有 1 次
terminal fallback 与已计入 Slow 的同一 snapshot 重叠，因此不重复计为重算。
P→D 全部为 Direct，无 Host 写入、恢复或释放。

c512 的 D→P Slow Host 写入与 D 源释放均为 378 次，Host→P 恢复与 extent
释放均为 373 次；其中 1 次恢复来自窗口前写入，另 6 次窗口内写入随后均走
application-final。Direct 有 1 次窗口前完成、窗口内绑定。P→D Host 写入
24,587 次、Host→D 恢复与 extent 释放均为 24,585 次；其中 56 次恢复来自
窗口前写入，58 次窗口内写入在窗口后恢复，因此净多 2 次在途。

c640 的 D→P Direct 有 6 次窗口内完成、窗口后绑定；Slow Host 写入 2,564 次，
Host→P 恢复 2,501 次、extent 释放 2,498 次。正式窗口内有 5 次恢复来自窗口前
写入；68 次窗口内写入未在窗口内恢复，其中 35 次在窗口后恢复、29 次走
application-final，另 4 次发生在窗口最后 0.15 秒并随实验结束清理。390 次持久
路径重算与 terminal fallback 一一对应，且不与 Direct/Slow 重叠。P→D Host
写入 22,049 次、Host→D 恢复与 extent 释放均为 22,088 次；61 次恢复来自
窗口前写入、22 次窗口内写入在窗口后恢复，因此窗口内净减少 39 条在途。
